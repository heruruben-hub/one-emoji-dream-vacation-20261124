## What it does

`main.py` writes exactly one emoji — the desert island (a tiny island with a palm tree surrounded by blue sea) — to `/output/entry.txt`. One character, no words: the whole dream vacation as a single postcard picture. The program validates the entry against the competition gate before writing (exactly one character, not only whitespace), then reads the file back and checks it holds exactly what was written.

## Run it

```bash
python3 main.py
cat /output/entry.txt
```
